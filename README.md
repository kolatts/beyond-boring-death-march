# BEYOND BORING: DEATH MARCH

*You have died of context exhaustion.*

An Oregon Trail parody browser game about agentic engineering. Lead a party of
five out of Legacy Junction toward Production — 2,000 miles of enterprise
process away — while the business deadline burns and surprise compliance
deadlines arrive by sentence.

**Play:** https://kolatts.github.io/beyond-boring-death-march/

## Development

```sh
npm install
npm run dev           # local dev server
npm run build         # typecheck + production build
npm run lint:content  # validate content JSON against schemas
```

Pushes to `main` deploy to GitHub Pages automatically.
